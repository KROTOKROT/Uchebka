# Frontend

React + TypeScript + Vite interface.

- Paste learning material into the editor or upload a UTF-8 TXT/Markdown file.
- Select 3–30 questions and a difficulty.
- Generate a quiz through the Spring Boot API.
- Complete the quiz and review the correct answers and explanations.

Configure the API URL with `VITE_API_URL` if the backend is not running at `http://localhost:8080/api`.
